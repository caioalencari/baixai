# Baixaí

Programa para Windows que baixa vídeos e áudios em MP3 ou MP4.

## Como usar

1. Baixe o `Baixai.zip` em [Releases](../../releases).
2. Clique com o botão direito no arquivo e escolha **Extrair tudo**.
3. Abra a pasta e dê dois cliques em `Baixai.exe`. Na primeira vez, ele oferece se instalar e criar um atalho na Área de Trabalho; depois disso, o zip e a pasta podem ser apagados.
4. Cole o link, escolha MP3 ou MP4 e clique em **Baixar**.

Se aparecer o aviso azul do Windows, clique em **Mais informações** e depois em **Executar assim mesmo**.

Se os downloads pararem de funcionar, clique em **Atualizar yt-dlp** dentro do programa.

Use apenas para conteúdo que você tem direito de baixar.
